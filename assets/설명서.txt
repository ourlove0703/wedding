==============================================================
 청첩장 수정 설명서  (ourlove0703.github.io/wedding)
==============================================================

[기본 규칙]
- 대부분은 config.js 파일 하나만 고치면 됩니다.
- " " (따옴표) 와 , (쉼표) 는 지우지 마세요. 하나만 빠져도 화면이 안 나옵니다.
- GitHub에 저장 후 1~2분 뒤 반영됩니다.
  예전 화면이 보이면 새로고침 또는 시크릿 창으로 확인하세요.
- 고치기 전에 원래 파일을 한 부 복사해 두면 안전합니다.


==============================================================
 1. config.js  (내용 바꾸기 - 거의 여기서 다 됩니다)
==============================================================

theme: "freesia"
  → 전체 색상과 분위기
     "freesia"  : 수채화 노랑 + 프리지아 꽃잎 날림 (현재)
     "blossom"  : 벚꽃 핑크 + 화이트
     "sage"     : 아이보리 + 세이지 그린
     "peach"    : 크림 + 피치 베이지
     "lavender" : 아주 옅은 라벤더 + 화이트

api: "https://script.google.com/..."
  → 참석 여부, 방명록이 저장되는 구글 시트 주소
     비우면("") 미리보기 모드 (실제로 저장되지 않음)

siteUrl: "https://ourlove0703.github.io/wedding/"
  → '링크 복사', '공유하기' 버튼에 쓰이는 주소

date: "2027-07-03", time: "13:10"
  → 예식 날짜와 시간 (달력, D-day, 첫 화면 날짜가 모두 자동으로 바뀜)

groom / bride
  ko: "정충용"           → 한국어 이름
  ja: "チョン・チュンヨン" → 일본어 이름
  short                  → 초대의 글 아래 짧은 이름 (충용, 소연)
  father / mother        → 부모님 성함
  order                  → 장남 / 장녀 등

greeting
  → 초대의 글. "..." 하나가 한 줄, "" 는 빈 줄

place
  name     → 예식장 이름
  hall     → 홀 이름
  address  → 주소 (지도 버튼, 주소 복사에 사용)
  tel      → 예식장 전화번호
  search   → 카카오맵, 네이버지도에서 검색할 단어

route (오시는 길) / notice (알아두실 것)
  icon: "🚗"  → 앞에 붙는 이모티콘 (빼도 됨)
  t           → 항목 이름 (자가용, 버스 ...)
  d           → 설명. 줄바꿈은 \n
  항목 추가: { icon: "", t: {ko:"", ja:""}, d: {ko:"", ja:""} },
             한 줄을 통째로 복사해서 붙여 넣고 내용만 바꾸기

photos
  main     → 첫 화면 큰 사진
  gallery  → 갤러리 사진 목록 (순서대로 나옴, 앞의 6장이 화면에 보임)

music: "music.mp3"
  → 배경음악 파일. 비우면("") 음악 버튼이 사라짐

accounts (마음 전하실 곳)
  bank: "국민은행", num: "123-45-6789"
  → 둘 다 채우면 계좌번호와 '복사' 버튼이 나옴
     비어 있으면 '확인 필요'로 표시됨


==============================================================
 2. photos 폴더  (사진 바꾸기)
==============================================================

banner.jpg   → 첫 화면 큰 사진
01~06.jpg    → 갤러리 사진
hall.jpg     → 오시는 길의 예식장 사진
og.jpg       → 카카오톡으로 링크 보낼 때 보이는 미리보기 사진
               (가로 1200 x 세로 630 권장)

- 같은 이름으로 덮어쓰면 그대로 바뀝니다.
- 사진을 더 넣으려면 07.jpg 처럼 올리고
  config.js 의 gallery 목록에 "photos/07.jpg" 를 추가하세요.
- 사진 1장은 1MB 이하로 줄여서 올리면 빨리 열립니다.


==============================================================
 3. index.html  (카톡 미리보기 문구, 제목 이모티콘)
==============================================================

<title> ... </title>
og:title / og:description
  → 카카오톡 공유 미리보기에 나오는 제목, 설명 문구
  ※ 카톡은 미리보기를 오래 기억합니다. 바꾼 뒤 안 바뀌면
    카카오 개발자 사이트 '공유 디버거'에서 주소를 넣고 초기화하세요.
    (developers.kakao.com/tool/debugger/sharing)

data-emo="💌"
  → 각 제목 위의 이모티콘
     💌 초대의 글   🗓️ 예식 일시   📸 갤러리   📍 오시는 길
     🔔 알아두실 것  💐 참석 여부   💬 방명록   💝 마음 전하실 곳
  → 따옴표 안의 이모티콘만 바꾸면 됨. data-emo="..." 를 통째로 지우면 이모티콘 없음


==============================================================
 4. assets/app.js  (화면 문구, 꽃잎 개수)
==============================================================

const PETALS = 22;
  → 첫 화면에 날리는 꽃잎 개수. 0 이면 꽃잎 끄기

TXT = { ko:{ ... }, ja:{ ... } }
  → 버튼, 제목 등 화면 문구 (ko 한국어 / ja 일본어)
     예) inviteTitle:"소중한 분들을 초대합니다"
         rsvpTitle:"참석 여부를 알려주세요"
         thanks:"귀한 걸음으로 축복해 주셔서<br>진심으로 고맙습니다."
     <br> 은 줄바꿈

lbMsg
  → 사진 크게 볼 때 아래에 나오는 인사 문구 (<span> 하나가 한 줄)

const E = { freesia: ["🌼", "💛"], ... }
  → 테마별 표지 이모티콘 / 맨 아래 이모티콘


==============================================================
 5. assets/style.css  (색을 직접 조정하고 싶을 때만)
==============================================================

html[data-theme="freesia"]{ ... }  ← 테마별 색상 묶음
  --main   → 제목, 버튼 색
  --point  → 테두리, 강조 색
  --paper  → 본문 바탕색
  --tint   → 색이 들어간 구간의 바탕색
  --heart  → 달력의 예식일 하트 색
  색은 #A65D6A 같은 6자리 색상 코드로 적습니다.

프리지아 꽃 장식 크기와 위치 (파일 맨 아래 '수채화 프리지아 테마')
  width:60%   → 꽃 장식 크기 (숫자가 클수록 큼)
  opacity:.6  → 진하기 (0 ~ 1, 1이 가장 진함)

==============================================================
 문제가 생겼을 때
==============================================================
- 화면이 하얗게 나오면 → 방금 고친 곳의 따옴표나 쉼표가 빠졌는지 확인
- 색이 안 바뀌면      → theme 철자 확인, 새로고침 또는 시크릿 창
- 사진이 안 나오면    → 파일 이름의 대소문자, 확장자(.jpg / .JPG) 확인
- 그래도 안 되면      → 저장해 둔 원래 파일로 되돌리기
