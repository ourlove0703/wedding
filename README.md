# 정충용 ♥ 이소연 모바일 청첩장

서버 없이 **GitHub Pages(무료)** 로 청첩장을 띄우고,
참석 여부·방명록은 **구글 시트(무료)** 에 쌓이는 구조입니다. PC를 꺼 둬도 24시간 동작합니다.

```
wedding/
├─ index.html          청첩장 화면
├─ config.js           ★ 내용 수정은 여기서만 (이름·날짜·계좌·구글시트 주소)
├─ assets/             디자인(style.css)·동작(app.js) — 고칠 필요 없음
├─ photos/             사진 (banner.jpg = 첫 화면, 01~06 = 갤러리, og.jpg = 카톡 미리보기)
├─ music.mp3           배경음악 (하객이 버튼을 눌러야 재생)
└─ apps-script/Code.gs 구글 시트에 붙여넣을 코드
```

---

## 1단계 · 내용 채우기 (`config.js`)

메모장이나 VS Code로 `config.js` 를 열어 빈칸(`""`)을 채우세요. 비워 둔 곳은 화면에 **"확인 필요"** 로 표시됩니다.

- 혼주 성함: `father`, `mother`
- 주차·대중교통 안내: `route`
- 계좌: `accounts` 의 `bank`(은행), `num`(계좌번호)

> 사진을 바꾸려면 `photos` 폴더에 같은 이름으로 덮어쓰면 됩니다. `06.jpg` 는 샘플 그림이니 실제 사진으로 바꾸세요.
> 갤러리 장수를 바꾸려면 `config.js` 의 `gallery` 목록을 고치면 됩니다.

## 2단계 · 구글 시트 연결 (참석·방명록 저장소)

1. https://sheets.new 에서 새 스프레드시트를 만들고 제목을 `청첩장 응답` 정도로 바꿉니다.
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본으로 있는 코드를 모두 지우고 `apps-script/Code.gs` 내용을 **통째로 붙여넣고** 저장(💾)합니다.
4. 위쪽 함수 선택 칸에서 **`setup`** 을 고르고 **▶ 실행** 을 누릅니다.
   - "승인 필요" 창이 뜨면 → 내 구글 계정 선택 → **고급 → (안전하지 않은 페이지)로 이동 → 허용**
     (내가 만든 코드라서 뜨는 정상적인 경고입니다)
   - 시트에 `요약`, `참석응답`, `방명록` 탭이 생기면 성공입니다.
5. 오른쪽 위 **배포 → 새 배포** → 톱니바퀴에서 **웹 앱** 선택
   - 실행 계정: **나**
   - 액세스 권한: **모든 사용자**
   - **배포** → 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. `config.js` 의 `api: ""` 따옴표 안에 붙여넣습니다.

확인: 웹 앱 URL 을 브라우저 주소창에 넣었을 때 `{"ok":true,"hello":"wedding api"}` 가 보이면 됩니다.

> **Code.gs 를 나중에 고쳤다면** → 배포 → **배포 관리** → 연필 아이콘 → 버전: **새 버전** → 배포.
> (새 배포를 만들면 주소가 바뀌니 꼭 "배포 관리"에서 수정하세요.)

## 3단계 · GitHub Pages 로 공개

1. GitHub 에서 **New repository** → 이름 `wedding` → **Public** → Create.
2. **Add file → Upload files** 에서 `wedding` 폴더 **안의 내용물 전체**를 끌어다 놓고 Commit.
   (`.nojekyll` 파일도 같이 올라가야 합니다. 안 보이면 git 으로 올리거나, 빈 파일을 같은 이름으로 새로 만드세요.)
3. 저장소 **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main` / `(root)` → Save.
4. 1~2분 뒤 `https://내아이디.github.io/wedding/` 로 접속됩니다.
5. 주소가 정해졌으니 아래 **3곳의 `YOUR-ID`** 를 내 GitHub 아이디로 바꿔 다시 올립니다.
   - `index.html` → `og:image`, `og:url` (카톡 미리보기용)
   - `config.js` → `siteUrl`

## 4단계 · 확인하고 보내기

- 휴대폰으로 열어 **참석 여부**와 **방명록**을 하나씩 써 보고, 구글 시트에 들어왔는지 확인하세요.
  테스트한 줄은 시트에서 행을 지우면 끝입니다.
- 카톡에 링크를 보냈는데 미리보기가 안 바뀌면:
  https://developers.kakao.com/tool/debugger/sharing 에서 주소를 넣고 **캐시 초기화**.
- 일본어 화면으로 바로 열리는 링크: 주소 끝에 `#ja` (예: `…/wedding/#ja`)

## 운영하면서

| 하고 싶은 일 | 방법 |
|---|---|
| 참석 인원 보기 | 구글 시트 `요약` 탭 (자동 계산) |
| 엑셀로 받기 | 구글 시트 **파일 → 다운로드 → Microsoft Excel** |
| 방명록 글 숨기기 | `방명록` 탭의 **숨김** 칸에 아무 글자 (30초 안에 반영) |
| 방명록 글 지우기 | 그 행 삭제 |
| 같은 사람이 참석 응답을 다시 보냄 | 연락처가 같으면 새 줄 대신 **기존 줄이 수정**됩니다 |
| 예식 후 | 동의 문구대로 `참석응답` 탭의 연락처를 지워 주세요 |

### 무료 한도 (참고)
- GitHub Pages: 월 100GB 전송 정도까지 여유 — 청첩장 1회 열람은 1MB 안팎이라 걱정 없습니다.
- Apps Script: 개인 계정 기준 하루 수천 건 처리 — 하객 수백 명 규모에는 충분합니다.
- 저장소가 Public 이라 코드와 사진은 누구나 볼 수 있지만, **응답·방명록 비밀번호는 구글 시트에만** 있습니다.
